# Contributing

Thanks for helping improve Open Source AI Review! 🎉

This project highlights open-source AI tools that are:

- Open source with a permissive license (MIT, Apache-2.0, BSD, etc.)
- Actively maintained (recent commits in the last 6 months)
- Useful in real-world workflows (not just demos)
- Relevant to one or more tags:
  - 🤖 AI Agents
  - 💻 Coding Agents
  - ⚙️ LLM Frameworks

---

## How to add a tool

1. **Fork** this repository.
2. Edit `README.md` and add your tool in the appropriate place.
3. Use the template below to keep formatting consistent.
4. Update the star/fork counts from the GitHub API or repo page.
5. Open a **Pull Request** with a short explanation of what you added.
